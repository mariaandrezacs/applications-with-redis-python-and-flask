# Flask-Redis Starter Kit

Starter Kit para aplicações web utilizando **Python**, **Flask** e **Redis**, com exemplos práticos de integração, cache e estruturação de projetos.

Este repositório serve como base educacional e técnica para quem deseja aprender ou iniciar projetos usando Flask com Redis de forma simples, organizada e extensível.

---

## ✨ Objetivo do Projeto

Demonstrar como utilizar o Redis em conjunto com Flask para:

- Cache de dados
- Armazenamento rápido em memória
- Organização de aplicações Flask
- Boas práticas de estruturação de projeto
- Base reutilizável para novos projetos

---

## 🛠️ Tecnologias Utilizadas

- Python
- Flask
- Redis
